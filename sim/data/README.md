# Data

This folder holds the necesasry data files for real world power source traces and will need to be populated yourself due to the size of files

## Bonito

[Zenodo](https://doi.org/10.5281/zenodo.6383042)

Download the files with the prefix `pwr_*.h5` to `./bonito` which can be used with the `BonitoSource` class. Typically the names for the nodes follows `node0` with `0` counting up based on the number of energy harvesters per dataset.
